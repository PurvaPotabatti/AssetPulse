## 📖 About

AssetPulse is a full-stack web application developed to simplify organizational asset management. It enables administrators to efficiently manage assets, employees, assignments, and maintenance requests while providing employees with a dedicated portal to view assigned assets, raise maintenance requests, and manage their profiles.

The application follows a secure role-based architecture using **Spring Security** and **JWT Authentication**, ensuring that users can only access resources permitted by their assigned roles. A React frontend communicates with the Spring Boot backend through REST APIs, with MongoDB Atlas serving as the database.
